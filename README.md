# 🌟 بوت نظام الدعوات وعجلة الحظ

بوت ديسكورد متكامل لتتبع الدعوات وإدارة نظام المكافآت مع عجلة حظ تفاعلية.

## ✨ المميزات

### 📊 نظام تتبع الدعوات المتقدم
- تتبع تلقائي لمن دعا من وعدد الدعوات
- سجل تفصيلي للدعوات والمدعوين
- إمكانية إضافة دعوات وهمية أو إزالة دعوات
- إحصائيات مفصلة عن دعوات كل عضو

### 🎮 نظام النقاط والمكافآت
- نقاط تلقائية للأعضاء عند دعوة أشخاص جدد
- إمكانية استخدام النقاط في عجلة الحظ للفوز بجوائز
- نوعان من العجلات: عادية وسوبر بتكلفة وجوائز مختلفة

### 🔗 روابط دعوة مخصصة
- إنشاء روابط دعوة سهلة ومخصصة
- تحديد مدة صلاحية الرابط (أسبوع افتراضيًا)
- تتبع استخدامات كل رابط

### 👤 ملفات تعريف المستخدمين
- عرض معلومات مفصلة عن المستخدمين
- إحصائيات الدعوات والنقاط لكل عضو
- معلومات عن من قام بدعوة العضو ومتى

### 🛠️ ميزات إدارية
- إضافة نقاط ودعوات للأعضاء
- تخصيص العديد من الإعدادات بسهولة
- حفظ البيانات في ملف قاعدة بيانات دائم

## 📋 قائمة الأوامر

### 🔗 أوامر الدعوات
- `-رابط` أو `-link` - إنشاء رابط دعوة جديد
- `-انفايت` أو `-invites` - عرض إحصائيات الدعوات
- `-انفايت @mention` - عرض إحصائيات دعوات شخص آخر

### 🎮 أوامر النقاط واللعب
- `-نقاط` أو `-points` - عرض نقاطك الحالية
- `-عجلة` أو `-spin` - لعب عجلة الحظ والفوز بجوائز

### 👤 أوامر المستخدمين
- `-هوية` أو `-user` - عرض معلوماتك
- `-هوية @mention` - عرض معلومات شخص آخر

### ⚙️ أوامر الإدارة
- `-اضافة-نقاط @mention العدد` أو `-add-points @mention amount` - إضافة نقاط لشخص
- `-اضافة-دعوات @mention العدد` أو `-add-invites @mention amount` - إضافة دعوات وهمية
- `-ازالة-دعوات @mention العدد` أو `-remove-invites @mention amount` - إزالة دعوات

## ⚙️ التثبيت والإعداد

1. قم بتثبيت Node.js (v16.9.0 أو أحدث)
2. قم بتنزيل أو استنساخ هذا المشروع
3. قم بتثبيت الاعتماديات:
   ```
   npm install
   ```
4. قم بفتح ملف `config.js` وضع توكن البوت في حقل `token`:
   ```js
   token: 'your_bot_token_here',
   ```
5. قم بتعديل باقي الإعدادات في ملف `config.js` حسب احتياجاتك (معرفات القنوات، البرفكس، إلخ)
6. شغّل البوت:
   ```
   node index.js
   ```

## 📂 هيكل المشروع

- `index.js` - الملف الرئيسي للبوت
- `config.js` - ملف الإعدادات والتكوين
- `database.js` - إدارة قاعدة البيانات وتخزين المعلومات
- `database.json` - ملف قاعدة البيانات (يتم إنشاؤه تلقائيًا)

## 📝 ملاحظات

- تأكد من إعطاء البوت الصلاحيات اللازمة في السيرفر
- يجب أن تكون للبوت صلاحية إنشاء الدعوات
- قم بالتأكد من تعيين التوكن ومعرفات القنوات الصحيحة في ملف `config.js`
